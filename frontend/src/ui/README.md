# UI

Small shared building blocks.

| File | Purpose |
|------|---------|
| `icons.tsx` | Stroke icons (no emoji in the UI) |
| `Toast.tsx` | `useToast().show(message, { tone, action })` — short notices, optional Undo action |
| `Menu.tsx` | Dropdown `Menu` / `MenuItem` / `MenuDivider`; optional controlled `open` |
